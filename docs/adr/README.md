# Architecture Decision Records (ADR)

This directory contains all major architectural decisions made during the development of GridWise AI.

Each ADR documents:

- The problem
- Available options
- Decision rationale
- Trade-offs
- Expected consequences

Recording these decisions makes the project easier to understand, maintain, and extend.
